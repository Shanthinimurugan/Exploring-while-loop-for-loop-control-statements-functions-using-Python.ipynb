# Exploring While Loop, For Loop, Control Statements & Functions Using Python
A comprehensive Python project focused on understanding loops, control statements, and functions through practical programming exercises and problem-solving tasks.

## 🎯 Project Objective

This project is a practical exploration of fundamental Python programming concepts, including **while loops, for loops, control statements, and functions**. It consists of simple programming exercises designed to strengthen logical thinking, problem-solving abilities, and understanding of Python program flow.

The project includes three practical tasks:

* Number Guessing Game using a `while` loop and control statements
* Multiplication Table Generator using a `for` loop and `range()`

## 📝 Tasks Included

### Task 1: Number Guessing Game

**Concepts Covered:** `while` loop, `if-elif-else`, `break`, `continue`

A simple number guessing game is created where the computer generates a random number between **1 and 10**. The user gets a limited number of attempts to guess the number.

The program:

- Generates a random number using `random.randint()`.  
- Allows the user a maximum of 4 valid attempts.  
- Checks whether the entered number is within the range of 1 to 10.  
- Uses `continue` when the input is outside the valid range.  
- Provides hints such as **"Too low"** or **"Too high"**.  
- Uses `break` when the correct number is guessed.  
- Uses the `while-else` structure to display a message when all attempts are exhausted.

### Task 2: Multiplication Table Generator

**Concepts Covered:** `for` loop, `range()`, user input

A multiplication table is generated for a number entered by the user.

The program uses:

```python
for j in range(1, 11):
```

to generate the multiplication table from **1 to 10**.

### Task 3: BMI Calculator

**Concepts Covered:** Functions, user input, arithmetic operations, formatted output

A user-defined function named `calculate_bmi()` is created to calculate the Body Mass Index (BMI) using the formula:

**BMI = Weight / Height²**

The program accepts the user's weight in kilograms and height in meters and displays the calculated BMI rounded to two decimal places.
